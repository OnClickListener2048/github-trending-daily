#2vercel-labs/agent-desktop

基于操作系统无障碍树的桌面 Agent 操作层，用快照 ref 代替像素猜测

💡 亮点
  • ref 带快照与构建版本命名空间，UI 变化时显式报 STALE_REF，动作可安全重试
  • 默认 headless：走无障碍 API 而非合成输入，不改焦点、不移动指针，--headed 才用物理输入
  • 错误响应带 disposition.retry，agent 只在标记 safe 时重试，重试策略由程序判断而非自然语言描述
🎯 它是什么

让 AI agent 操作桌面应用时不再靠截图猜像素，而是先读取应用真实的 UI 结构，再执行点击和输入。它以统一的 CLI 和 C 库覆盖 macOS、Windows 和 Linux，每条命令输出一个 JSON 响应，便于 agent 循环调用。

⚙️ 技术方案

Rust 直接读取 macOS AX、Windows UIA、Linux AT-SPI 无障碍树；ref 绑定快照命名空间（@s8f3k2p9:e8），直接使用裸 ref 会报 INVALID_ARGS，UI 变化则返回 STALE_REF 或 AMBIGUOUS_TARGET；macOS 侧有常驻命令宿主保留原生 AX 对象，防止被删除的行被错误解析到同名的存活行，动作默认不移动指针也不抢占焦点。

👥 适合谁

做 computer-use agent 的框架作者、跨平台桌面自动化与 RPA 工程、UI 端到端测试团队

🔥 为什么火

Vercel Labs 品牌加上 computer-use 热潮，且给出「不靠截图、改用无障碍树」的明确替代路线；单日新增 2,243 约占总量 26%，属于集中发布后爆发，而非自然增长。

#3thedotmack/claude-mem

为多款 AI 编程 Agent 提供跨会话持久记忆与上下文压缩的中间层。

💡 亮点
  • 跨 Agent 兼容 Claude Code、Codex、Gemini、Copilot、OpenCode 等，用统一记忆层避免被单一助手锁定
  • 自动捕获→AI 压缩→相关上下文回注形成闭环，减少手动维护 CLAUDE.md 或粘贴历史
  • 提供 MCP 搜索工具供 Agent 主动检索历史观察，npx 一条命令安装，并有 30+ 语言 README
🎯 它是什么

它把 Agent 会话中的工具调用、观察与决策自动记录下来，用 AI 压缩成语义摘要，并在后续会话注入相关片段，解决重开对话即丢失项目上下文的痛点。

⚙️ 技术方案

基于 Claude Code 钩子捕获会话事件，后台生成语义摘要进入记忆库，再通过 MCP 搜索工具按需回注；TypeScript 编写、要求 Node 20+，并以适配层兼容多种 IDE/Agent。

👥 适合谁

长期使用 Claude Code、Codex 等编码 Agent 的开发者，以及需要跨会话续接大型项目的团队。
