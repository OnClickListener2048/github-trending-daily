  • 纯 C 实现，零依赖，每个模型家族一个文件，不强制要求显卡；可用 CPU，也可通过 Vulkan 走任意 GPU，或通过 CUDA 走 NVIDIA 卡
  • 一步式安装脚本：自动探测内存、空闲磁盘、CPU 与 GPU，推荐装得下的模型，缺少编译器时回退到预编译版本，缺少依赖时打印确切的安装命令后继续用 CPU 跑
